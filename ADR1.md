# ADR 001 - Selection of Development Framework

## Status - Accepted

## Context

MiniGamez requires a framework that supports building an interactive application with multiple screens and reusable components. The team needs a framework that is suitable for the scope of our project and a framework that is familiar to all members
## Decision
The team has chosen React Native(expo) as our development framework
## Consequences
- Allows the team to build the application using TypeScript and React concepts.
- Supports reusable components and state management.
- Expo simplifies the development and testing process.
- Team members are already familiar with React Native so development can begin immediately.
